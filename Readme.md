В файле main.py реализовано CRUD приложение.
Описаны метрики:
- Histogram для latency и Counter для числа ответов с лейблом кода.
Использую Histogram, а не Summary, так-как нельзя сложить перцентили от двух разных подов.
Histogram будет хранить значения для каждого пода и можно будет найти перцентиль 

Написан dockerfile и docker-compose.yaml, поднимается 2 эксземляра приложений (цоды), Grafana и prometheus.yaml

dashboard.py формирует json используя список ручек, для каждой добавляет 3 панели.
